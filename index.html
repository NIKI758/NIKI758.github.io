One Playwright framework, 180+ suites

Architected an end-to-end Playwright framework with a modular, functional-helper architecture, covering cross-browser regression, smoke and sanity testing. Re-authenticating with 2FA on every test is slow, so I built a custom worker-reuse patch and a persistent session manager with TOTP/2FA credential pooling — sessions stay alive and workers stop paying the login cost.
